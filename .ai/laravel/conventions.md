# Laravel Coding Rules

1. Follow PSR-12 + Laravel Pint
2. Thin Controllers
3. Business logic in Services
4. Complex queries in Repositories
5. Validation via FormRequest
6. API output via Resource
7. Use DTO when needed
8. Use snake_case for DB
9. Use PascalCase for classes
10. Use camelCase for methods
11. Always use migration
12. Always use seed/factory
13. Never hardcode secrets
14. Write tests for critical flows
